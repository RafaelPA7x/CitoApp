# CitoApp

> Uma experiência gamificada para dominar a **Citologia**, do Ensino Médio ao vestibular.

Projeto da disciplina **Experiência Criativa**, **PUCPR · 2026**.

## Sobre o projeto

O **CitoApp** é uma ferramenta criada por estudantes, para estudantes. Ele une tecnologia, gamificação e biologia para transformar o estudo da Citologia em uma experiência mais ativa e memorável.

| **Acessível** | Intuitivo para qualquer estudante do Ensino Médio. |
| **Gamificado** | Interações ativas que ajudam a fixar o conteúdo. |
| **Focado no vestibular** | Cobertura dos tópicos mais cobrados. |

## Gamificação

O CitoApp vai além da leitura passiva: o usuário interage diretamente com o conteúdo.

- **Cliques:** complete as células acertando as organelas destacadas.
- **Digitação:** responda perguntas abertas para testar seu conhecimento.
- **Pontuação individual:** o desempenho é refletido em um score, o que estimula a revisão contínua.

## Conteúdo abordado

O app cobre os três grandes grupos celulares, com detalhes sobre estruturas, organelas e funções essenciais:

| Tipo celular | Características |
|---|---|
| **Procariótica** | Bactérias e arqueas, sem núcleo definido. |
| **Eucariótica animal** | Células com núcleo e organelas complexas (mitocôndrias, lisossomos, centríolos), sem parede celular. |
| **Eucariótica vegetal** | Cloroplastos, parede celular de celulose e vacúolo central. |

## Tecnologias utilizadas

- **Java**, por meio do **[Processing](https://processing.org/)**

## Como executar

1. Instale o [Processing](https://processing.org/download).
2. Clone este repositório:
   ```bash
   git clone https://github.com/RafaelPA7x/CitoApp.git
   ```
3. Abra o arquivo `.pde` principal do projeto no Processing.
4. Clique em **Run** (▶) para executar.
